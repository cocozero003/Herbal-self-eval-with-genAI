# Restricted dataset provenance and reproduction

Public GitHub intentionally omits the V3-derived research proxy input files and any archived researcher manuscript. The complete authorized package is stored in the user's ThaiHerb project Google Drive:

https://drive.google.com/drive/folders/11ZhI1j3fpmYS9KixG5E_1pw03pqC5fIe

For reproducibility, download the full research ZIP and preserve the directory structure. Run `python run_v08.py` from the package root. The four frozen input files are:

- `data/paper1_bootstrap_v3_proxy.json`
- `data/formula_reviewed_snapshot.json`
- `data/CHEMICAL_IDENTITY_TAXONOMY_25.csv`
- `data/CHEMICAL_ASSERTION_EVIDENCE_REVIEW_30.csv`

The primary formula compendium is accessible through the public DTAM website and is not redistributed here. The chemistry labels have been curated in a later V3-derived project stage. **Neither the 19-class original table nor the original trained model archive is recovered.** The chemical review cites candidate source literature but is not independent specimen-level adjudication. The original ten-herb journal manuscript and numerical study are preserved separately.

A user of the public GitHub-only code cannot run the data-dependent computations until the authorized complete package's inputs are supplied.
