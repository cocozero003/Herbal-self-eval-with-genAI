# Provenance and sharing

The `paper2_bootstrap_v3_proxy.json` is a V3-derived 20-herb projection, not the original Paper 2 raw study archive. The `paper1_formula_reviewed_snapshot.json` contains ten legacy formula projections reviewed by one AI-assisted curator. Original 35 compound-class table and full archived 190-pair model vectors have not been recovered.

Distribution of the complete research dataset is limited to the project's authorized Google Drive folder. The public GitHub branch contains source code and methodological documentation only, with data-loading instructions.
