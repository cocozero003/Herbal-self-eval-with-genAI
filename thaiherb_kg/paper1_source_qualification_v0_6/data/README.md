# Research input boundary

The public source-code folder is **not standalone**. Retrieve the full private/authorized Paper 1 v0.6 research ZIP from the project Google Drive folder:

https://drive.google.com/drive/folders/1UmK9BqlQOmZmbn-tiKZh_KFbaRZjJJ6J

Extract the full ZIP preserving paths. The v0.6 scripts depend on original v0.5 proxy inputs and exploratory model results, including `data/paper1_bootstrap_v3_proxy.json`, `results/CHEMICAL_ASSERTION_EVIDENCE_REVIEW_30.csv`, `results/CHEMICAL_IDENTITY_TAXONOMY_25.csv`, `results/formula_reviewed_snapshot.json`, and `results/19_class_candidate/embedding_cosine_45pairs_10seeds.csv`.

The original Paper 1 chemistry archives and 19-class mapping are NOT recovered; results are not an exact reproduction of that manuscript. All post-hoc added citations must not be treated as an independent test set. Expert labels stay blank. Do not upload the original manuscript, full dataset, or copyrighted source PDFs to this public repository without authorization.
