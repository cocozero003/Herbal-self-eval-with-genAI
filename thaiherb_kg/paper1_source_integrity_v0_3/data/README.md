# Research data (not distributed in public GitHub)

The script requires `data/paper1_bootstrap_v3_proxy.json`, an explicitly unverified V3-derived projection. It is **not** the original Paper 1 training data. Download the authorized `ThaiHerb_Paper1_SourceIntegrity_v0.3_2026-11-07.zip` from the project Google Drive folder `Paper 1 - ThaiHerb10 Feasibility / Source_Integrity_Audit_v0.3_2026-11-07`; extract `data/paper1_bootstrap_v3_proxy.json` here. The original reviewed manuscript is retained in the Drive package only.

After installing `requirements.txt`, run `python run_all.py` from the project directory. Do not interpret the results as a verified primary-source knowledge graph. Formula memberships still include 32 unreviewed rows, and original chemistry classifications are not recovered.
