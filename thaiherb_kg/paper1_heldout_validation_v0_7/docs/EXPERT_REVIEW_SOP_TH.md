# SOP — Blinded Independent Herb-Pair Evaluation สำหรับ Paper 1

**สถานะ:** พร้อมใช้เป็นแบบฟอร์ม แต่ยังไม่ได้รับคะแนนจากผู้เชี่ยวชาญอิสระ

## Purpose และการแยกผลลัพธ์

ทดสอบ 45 คู่สมุนไพร 2 มิติแยกกัน ห้ามสรุปเพียงว่า “คล้ายกัน” โดยไม่มีบริบท

- **Chemical composition similarity:** 0 = มีหลักฐานอิสระว่าต่างกันในบริบทที่เทียบกันได้, 1 = พบองค์ประกอบร่วมบางส่วนแต่หลักฐานยังจำกัด, 2 = มีหลักฐานอิสระที่เหมาะสมหลายรายการแสดง profile ที่สอดคล้องกัน; NA = ไม่พอประเมิน
- **Formula-context relatedness:** 0 = แหล่งสูตรอิสระที่ตรวจสอบในขอบเขตที่กำหนดไม่รองรับการใช้ร่วมกัน, 1 = พบการใช้ร่วมกันจำกัด, 2 = พบหลักฐานจากตำรับอิสระหลายแหล่งโดยมีบริบทชัดเจน; NA = ยังไม่พอประเมิน

**สำคัญ:** 0 มิใช่ “ไม่สัมพันธ์ทางเภสัชวิทยา” หากไม่มีหลักฐานที่ยืนยันความต่าง ต้องใช้ NA

## การทำงาน

1. ผู้ประเมิน R1 และ R2 ใช้ `BLINDED_EXPERT_R1_45.csv` / `BLINDED_EXPERT_R2_45.csv` ที่จัดลำดับไม่ตรงกัน
2. ทั้งสองไม่เห็นผล Graph Embedding, model rankings, NPMI หรือสูตรทดสอบระหว่างให้คะแนน
3. ใช้เอกสาร primary literature หรือ compendia ที่ไม่ถูกใช้ในการสร้าง original 10 formulas และไม่ใช่แหล่งเคมีใน V3/V05/V06; ระบุ DOI/URL/หน้า/ตารางและข้อมูล accession, botanical identity, plant part, preparation
4. หากแหล่งข้อมูลเป็น review สรุป secondary ต้องระบุและไม่นับเป็น independent primary confirmation โดยอัตโนมัติ
5. ผู้จัดการ dataset ตรวจ source disjointness ก่อนเปิดคะแนนโมเดล แหล่งที่ซ้ำให้สถานะ U/N แทน Y
6. เมื่อมีความไม่ตรงกันให้ reviewer ที่สามบันทึกเหตุผลใน `ADJUDICATION_TEMPLATE_45.csv`; ไม่คำนวณฉันทามติอัตโนมัติ
7. รัน `python src/evaluate_expert_labels.py` โปรแกรมจะ BLOCK หากคะแนนไม่ครบ/ขาดหลักฐานอิสระ และไม่รับรอง reviewer independence เอง

## วิธีรายงาน

- นับแต่ละมิติแยกกัน, Cohen's weighted kappa, ความถี่ NA, นับข้อจำกัดด้านบริบท
- เปรียบเทียบ Spearman และ nDCG@10 กับโมเดลที่ตรึงไว้แล้ว โดยไม่ย้อนเลือก hyperparameters จาก Gold
- เก็บ raw ratings, adjudication, source locator และ manifest ไว้โดยจำกัดสิทธิ์ก่อนเผยแพร่

## Scientific integrity

ผู้ช่วย AI ช่วยเตรียม rubric และตรวจความสอดคล้องของเอกสารได้ แต่ไม่สามารถทำหน้าที่เป็นผู้เชี่ยวชาญอิสระสองคนหรือสร้างคะแนนอิสระขึ้นมาแทนผู้ประเมินจริง
